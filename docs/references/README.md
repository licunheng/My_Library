# 通用参考

存放不专属于某一颗芯片、也不专属于某一个项目的材料，例如：

- 协议或标准的阅读摘要（注明标准编号和版本）
- 常用工具的配置备忘
- 外部文档链接和检索关键词

## 怎么放

- 一篇主题一个 Markdown，文件名用英文小写和连字符，例如 `i2c-timing-notes.md`。
- 原文和笔记属于同一主题时，放在以主题命名的子目录里。
- 摘录注明出处：文档名、版本、章节或页码。
- 大 PDF 的处理与芯片资料相同，见仓库根目录 `README.md`。

材料主要服务某一型号或某一个项目时，放到 `docs/chips/` 或 `docs/project-experience/`，在这里只留一条链接。
